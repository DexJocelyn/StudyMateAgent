# 课伴 StudyMate

面向课程小组作业的协作应用：围绕同一个项目保存作业要求，与AI确认分工、安排日程并跟进任务；提交前进入交付检查，人工核对材料缺项，再将补充任务带回工作台。交付检查是项目中的一个环节，原有任务、日程、成员与对话继续作为主要工作界面。

技术栈：Python 3.11+、FastAPI、qwen-plus、官方 MCP Python SDK、SQLite、原生 HTML/CSS/JavaScript。前端无需 Node 构建，Markdown库随源码提供。

当前版本：2026年11月6日，详见[本版更新与验证](docs/版本更新_20261106.md)。完整源码支持本机运行；GitHub仓库本身不是已部署的网站入口。

## 本次主流程

1. 首页新建小组项目，填写成员；点“帮我分工”输入老师要求；需要保存原文时，展开“已保存的作业要求与检查进度”。
2. 返回项目，点击“帮我分工”，补充截止时间后发给AI，确认任务草案并跟进日程。
3. 提交前点击“检查作业”，添加TXT、Markdown或DOCX正文材料。
4. 运行真实AI自查，通过MCP读取材料与保存分析，校验引文和材料版本。
5. 逐项查看要求、材料引文及行号，人工标记“确认”或“需补充”。
6. 确认负责人、未来截止时间和估时，生成补充任务，返回同一项目定位并继续处理；可导出自查报告。

找到文字依据不是质量合格。不会自动评分、识别图片或执行OCR，也不会验证图片真实性、链接可访问性及程序运行效果。完整说明见 [作业自查使用说明](docs/作业自查_使用与验收说明.md)。

## 功能

- 任务：创建、查询、修改，支持待开始、进行中、已暂停、已完成及明确转交。
- 日程：读取实际任务和可用时段，检查冲突、截止与工时覆盖，确认草案后保存。
- 记忆：按项目和聊天成员保存历史、当前任务焦点及待确认草案。
- 工具：16个独立 MCP 工具（含新增的自查读取、分析保存及补充任务工具），通过 stdio 执行数据库操作和外部查询。
- 搜索：可选 Tavily 基础搜索，展示实际来源并随对话保存。
- 天气：Open-Meteo 城市查询、当前天气模型估计及今明两日预报，无额外天气密钥。
- 网页：任务看板、日程、成员与项目切换、实际工具进度和计划下载。
- 语音：浏览器识别、可编辑转写、暂停/继续/停止输入与回复朗读。

## 安装与启动

### 教室内共同使用（Mac 主机＋Windows 客户端）

Mac 双击 `启动教室共享.command`，把显示的内网地址提供给同一 Wi-Fi 下的组员。组员使用 `dist/课伴教室版-Windows客户端安装包.zip`，解压后双击“安装课伴.cmd”，无需配置 Python 或模型密钥。项目数据保存在同一台 Mac，任务和日程看板会在空闲时自动更新。

完整步骤、网络限制及 Windows 实机验收见 [教室共享与Windows客户端](docs/教室共享与Windows客户端.md)。安装包是连接共享服务的轻量入口，Mac 需保持运行。校园设备隔离仍需通过共同热点或路由器解决。

先安装 Python 3.11 或以上版本，在自己的电脑创建虚拟环境；不要复制他人电脑的 `.venv`。

### Windows

解压或克隆源码后，双击 `启动课伴-Windows.bat`。启动器会选择可运行的 Python，创建本机环境并安装锁定依赖。首次运行需要联网下载依赖，终端不能关闭。

也可在 PowerShell 手动运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe scripts\check_env.py
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python scripts/check_env.py
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

macOS也可双击 `启动课伴.command`。启动后打开 [本机网页](http://127.0.0.1:8000/)，按 Ctrl+C 停止服务。单进程运行，不启用多 worker。

## 演示模式与真实模型

组员希望使用其他模型时，见 [组员接入自己的模型](docs/组员接入自己的模型.md)。当前支持兼容 Chat Completions、工具调用和 JSON 模式的接口；每个后端进程共用一套配置，网页切换成员不会自动切换模型。

项目内的AI交付检查必须使用 `AGENT_MODE=llm` 和真实模型密钥；未配置时可以保存材料，但不会返回模拟自查结果。

原任务功能默认 `AGENT_MODE=demo`，无需模型密钥，仅支持有限规则指令。MCP和数据库操作是真实的，但不能把规则演示当作大模型能力证明。

首页即项目工作台；`/tasks`仍兼容旧入口，`/review?project_id=项目编号`为项目交付检查。新建项目后，选择自己的聊天成员，可先试“拆解演示作业”，检查并采用草案，再使用任务卡片和导出按钮。

自由对话需复制 `.env.example` 为 `.env`，在本机配置：

```dotenv
AGENT_MODE=llm
MODEL_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
MODEL_NAME=qwen-plus
MODEL_API_KEY=在本机填写
```

使用百炼业务空间密钥时，Base URL应填写该业务空间提供的OpenAI兼容地址，以 `/compatible-mode/v1` 结尾，地域和密钥需对应。密钥只在服务器端使用，修改后重启。

搜索在同一 `.env` 增加 `TAVILY_API_KEY`；应用默认每月限制100次搜索尝试，失败也计数，短期缓存不重复调用。天气默认启用，可设置 `WEATHER_ENABLED=0` 关闭。天气免费接口适用于非商业教学场景，模型回复仍消耗供应商额度。

## 简单体验

成员选择后默认查看“我的任务”；“安排我的时间”只生成和替换当前成员的日程，其他成员安排保留。右侧可切换“全组”查看或明确安排整个项目。操作说明见 [个人任务与时间安排](docs/个人任务与时间安排.md)。

下面为原任务功能的体验流程，新自查流程见上方；点击“任务与日程”进入。

1. 新建“练习·自己的姓名”项目，填写本人和可选组员。
2. 描述作业要求、未来的明确截止时间和分工需求，检查草案后采用。
3. 给成员保存可用时间，生成日程草案，检查后采用。
4. 对自己的任务依次开始、暂停、继续；查看工具记录和任务卡片。
5. 导出计划，下载文件核对任务状态与日程。
6. 在模型模式可问“今天广州天气如何”，或要求搜索公开资料。

日期示例需要替换为使用当天之后的时间。未知城市、负责人或不明确指代应先澄清，不能根据模型一句“成功了”判断操作完成。

## 测试

在安装好依赖的虚拟环境中运行：

```bash
python -m pytest tests -q
python scripts/smoke_mcp.py
```

自动测试使用独立临时库和受控供应商响应，不消耗真实模型额度；MCP冒烟执行真实协议及数据库操作。2026年11月6日发布前验证：210项Python测试、20项前端Node测试，以及16个工具的MCP发现与业务冒烟通过。

前端语音测试可使用 `node --test tests/test_speech.mjs`。完整前端测试使用 `node --test tests/*.mjs`，需要开发环境安装 `jsdom`，通过 `STUDYMATE_TEST_JSDOM` 指定其绝对模块目录；运行网页本身不需要Node或jsdom。

真实供应商验证必须显式加 `--run`，会使用模型/搜索额度：

```bash
python scripts/verify_weather.py --run
python scripts/verify_web_search.py --run
```

## 范围与已知问题

- 成员视角是手动选择，不是个人账号登录或细粒度权限。
- 每个项目独立排程，尚不检查跨项目冲突和任务依赖。
- 天气是模型估计，需核对数据时间；网页搜索摘要可能滞后。
- 语音受浏览器、设备和网络影响；已有实测显示手动停止朗读未正常生效。
- 模型有时会遗漏调用或给出错误参数，需结合工具记录和实际数据核对。
- 数据默认在本机 `data/`，源码不含任何真实任务或密钥；不同电脑不会自动同步数据。
- 可用带密码网关的临时分享启动器，需主机保持运行。GitHub托管源码，不会自动把Python网站部署上线。
