# 回复排版更新

修复此前将助手Markdown回复直接当纯文本显示的问题。标题、加粗、斜体、列表、引用、表格、行内代码、代码块和引用链接现在正常排版；旧对话刷新后同样生效，不改写原数据库内容。用户自己的输入仍按原文显示。

标题使用适度字号，正文保留段落与列表间距；代码块保留原始字符，表格可横向滚动。引用链接在新标签打开，裸URL后的中文标点及句子不会被吞入链接。朗读使用页面排版后的文字，不直接朗读Markdown符号。

本次只改前端，没有修改模型提示、接口、数据库结构或收费设置，没有调用付费模型。解析器marked18.1.1和过滤器DOMPurify3.4.17已校验并打包在frontend/vendor，页面只加载本地文件，ROG不需要安装Node或访问CDN。库来源和许可证见vendor目录。

## 本机

刷新课伴网页即可。旧回复仍是原文，只改变显示方式。

## ROG

使用本次“ROG联网搜索与排版更新包”。它包含之前的联网搜索改动和这次的前端修复。

1. 停止服务并备份ROG原程序与data。
2. 按原目录合并更新包的backend、frontend、scripts等文件；不要遗漏frontend/markdown.js和整个frontend/vendor目录。
3. 保留ROG真实.env、.env.share、data和.venv。如果ROG助手另改过同名文件，先让它合并差异。
4. 如尚未配置搜索密钥，在ROG.env追加TAVILY_API_KEY。只做显示修复不需要新密钥。
5. 重新启动服务、刷新浏览器。若此前已安装联网搜索版，数据库无需额外处理；首次安装搜索版会自动新增用量表，不替换原业务数据。
