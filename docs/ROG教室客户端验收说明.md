# 在 ROG 上验证课伴教室客户端

将 `课伴教室版-Windows客户端安装包.zip` 传到 ROG，完整解压。Mac 先运行“启动教室共享.command”，双方连接同一个 Wi-Fi 或热点。

## 可以复制给 ROG 助手的说明

请协助验收这个课伴 Windows 客户端包。它是连接 Mac 共享服务的轻量入口，不是在 ROG 上另开一个独立后端。当前任务是实际安装、连接和验收，不需要安装 Python，也不需要填写或索取千问 API Key。

1. 阅读解压目录里的“先看这里.txt”和三个透明 CMD 客户端脚本，确认路径位于当前用户的 `%LOCALAPPDATA%\StudyMate\ClassroomClient`，不会修改系统执行策略。
2. 运行“安装课伴.cmd”，验证桌面生成“课伴教室版”和“课伴-修改主机地址”，开始菜单生成启动、修改地址、卸载入口。
3. 打开“课伴教室版”，填写 Mac 显示的共享地址。教室模式无需账号密码；进入后选择自己的成员姓名。
4. 验证能打开与 Mac 相同的项目。只在明确标注为“教室共享·双端验收”的测试项目里测试：在一台电脑修改任务标题或状态，另一台保持页面空闲，检查约3秒内自动更新；检查未发送的文字不丢失。
5. 验证下载任务计划、保存老师要求、上传/移除一份自己创建的临时测试材料。
6. 验证“修改主机地址”能重新打开地址输入框，取消时不覆盖原地址。不要关闭防火墙、绕过浏览器证书警告或降低 PowerShell 执行策略。
7. 若失败，记录 Windows 版本、PowerShell 版本、完整错误和失败步骤。连接日志在 `%LOCALAPPDATA%\StudyMate\ClassroomClient\client.log`。若浏览器也无法打开主机地址，先排查同一 Wi-Fi 下的设备隔离或主机未开启；必要时共同连接允许设备互访的热点。

Mac 上已完成网关与共享数据库的真实接口测试、自动同步的前端回归测试及客户端包结构检查。Windows 实机安装、Edge 应用窗口以及跨设备 Wi-Fi 互访尚待这次验收，请如实记录结果。
