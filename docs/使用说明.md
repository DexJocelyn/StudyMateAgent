# 课伴使用说明：先完成一次最简单的操作

先记住三个概念：

- **项目**：一份独立的工作空间。例如“软工小组”“数据库小组”“个人任务”。
- **成员**：这个项目里的负责人，可以只有你一个人。
- **任务**：要做的具体事情，包含负责人、截止时间、预计用时和状态。

开始聊天前，在顶部“当前聊天成员”选择自己的姓名。单人项目会默认选择唯一成员；多人项目需要自行选择。

## 先确认当前能用什么

本机已于 2026-10-20 配置好真实千问模型并通过基础联调。刷新后，如果顶部显示“已连接模型”，可以直接输入自然语言、粘贴作业要求；任务 ID 和工具名称不需要自己填写。例如：“帮我把下面的作业拆成任务，按当前成员分工，截止时间是 2026-10-25 晚上十点。作业要求：……”。模型可能先询问信息，拆解出的草案需要检查后确认保存。

如果页面显示“演示模式”，说明还没有接入真实模型。可以使用下面的固定句式、示例作业和按钮，操作会真正保存到数据库。

**演示模式暂时不能理解任意聊天，也不能根据你粘贴的任意作业智能拆解。** “拆解示例作业”只生成固定示例。新电脑拿到的源码不含密钥，需要自行配置真实模型才能自由描述需求。

## 第一次用：跟着做这五步

### 第一步：打开网页

在运行课伴的电脑上打开：<http://127.0.0.1:8000/>。

网页打不开时，双击项目文件夹里的“启动课伴.command”，等待启动后再打开网页。已有服务运行时不需要再次启动。

### 第二步：建一个练习项目

1. 点击顶部“新建项目”。
2. 项目名称填：`练习项目`。
3. “你的姓名或昵称”填自己的姓名，例如：`小林`。一个人练习时不用添加组员。
4. 点击“创建并进入”，会自动以小林的身份进入聊天。

页面顶部“当前项目”应显示“练习项目”。这是新的空项目，不会改动原来的小组。

### 第三步：创建一个任务

把下面这一整句话复制到“对话”的输入框，再点击“发送”：

```text
创建任务：整理报告，我，60分钟，2026-10-25 22:00截止
```

这句话的意思是：由“我”负责“整理报告”，预计用一小时，10 月 25 日晚上十点截止。

在“任务”区域应出现“整理报告”。电脑宽屏时任务在对话旁边；窄窗口时在对话下面，需要向下滚动。

**日期是示例。实际使用请改成自己的截止日期，姓名必须与当前项目成员一致。** 演示模式保持这个句式、中文逗号和日期格式，比较容易成功。

### 第四步：开始、暂停和完成任务

卡片上会明确显示负责人。自己的任务可直接更新状态；别人的任务需先点“切换为某某后操作”，进入该成员的独立聊天后再操作。切换视角不转交任务，只有“转交给…”会改变负责人。这是本机视角操作流程，尚不是登录账号的权限控制。

在“整理报告”这条任务下面：

1. 点击“开始任务”，状态变为“进行中”。
2. 暂时没空时，点击“暂停任务”，状态变为“已暂停”。
3. 有空后点击“继续任务”，回到“进行中”。
4. 真正做完后点击“标记完成”，状态变为“已完成”。

暂停和继续可以反复操作，刷新后仍会保留状态。暂停不会自动改变截止时间或已有日程，也不会减少预计用时；需要改期时再调整日程。可以用“已暂停”筛选找回搁置的任务。

日常使用时，真正做完这件事再标记完成。练习时可以体验一次状态变化。

### 第五步：导出

1. 点击顶部“导出计划”。
2. 对话里会出现文件下载链接。
3. 点击链接，下载 `.md` 文件。

这是 Markdown 文本文件，可以用文本编辑器或支持 Markdown 的软件打开。里面应有当前项目名、任务、负责人和完成状态。

**走完这五步，就已经学会基本使用：建项目 → 建任务 → 更新进度 → 导出。**

## 需要系统帮你安排时间时

排程针对“还没完成”的任务。先创建一条未完成任务，再继续下面的操作。

1. 点击顶部“设置空闲时间”。
2. 选择负责这条任务的成员，例如“我”。
3. 添加明确的开始、结束时间。例如：`2026-10-22 19:00` 到 `2026-10-22 20:00`。
4. 点击“保存”。时段要在当前时间之后、任务截止之前，而且足够完成任务。
5. 点击对话输入框上方的“安排日程”。
6. 如果时间足够，会出现“日程草案”。检查后点击“确认并保存”。
7. 切到“日程”，查看已保存的安排。

示例日期需要随实际使用日期调整。预计 60 分钟的任务至少需要 60 分钟空闲时间；不够时，课伴会说明缺口，补充时段后重新安排。

每次保存空闲时间会替换该成员的全部时段，已有时段会先显示在表单里。要增加时段，保留原来的行，再点“添加时段”。

已排程任务修改负责人、截止或预计用时可能会被拒绝。需要先到“日程”清空旧安排，再修改并重新排程。任务标记完成后，会移除它对应的待办日程块。

## 换成你自己的小组

### 创建另一个小组

点击“新建项目”，例如：

- 名称：`数据库课程小组`
- 你的姓名或昵称：`小林`
- 点击“添加组员”，分别填入`小张`、`小李`，每人一栏；不需要手动分隔。填错可移除，同名请用不同昵称区分。

创建后会以填写的本人姓名进入聊天，这个项目有自己的成员、任务、时间和对话。顶部“当前项目”可以切回其他小组。填写名单不会发送邀请，也不等同于账号注册。

各项目独立排程。目前不会把同一个人在不同项目的日程合并检查。

### 调整成员

点击顶部“成员”：

- 添加：填姓名后点“添加成员”。
- 改名：修改姓名后点对应的“改名”。
- 移除：点“移除”。如果该成员还有任务，先到任务列表使用“转交给…”把任务交给别人。

至少保留一名成员。人数与任务数量没有对应限制：三个人可以负责十项任务。

### 体验示例拆解

点击“拆解示例作业”，会出现一份固定模板的任务草案，按当前成员轮流分配。

草案尚未保存；点击“确认并保存”后，才会进入任务列表。每次生成并确认新的任务草案会新增任务，练习时不要反复确认多份相同示例。

它不是根据当前课程作业生成的智能拆解，适合熟悉操作。

## 常见疑问

**为什么粘贴作业后没有正常拆解？**

先看模式提示。演示模式只支持固定规则；需要先配置真实模型，再验证任意作业的智能拆解。配置步骤见 [README](../README.md#接入真实模型)。

**为什么任务保存了，却没有日程？**

任务与日程分开。先保存任务，再设置空闲时间，生成日程草案，最后确认保存。

**为什么“把它完成”没有找到任务？**

当前会话可能没有唯一的焦点任务，特别是刚批量创建了多条任务。初次使用直接点击任务上的“标记完成”最清楚。

**刷新后数据还在吗？**

在同一台电脑、同一份数据目录里，项目和任务会保留，浏览器也会尝试恢复当前项目的最近会话。

**为什么组员打不开我的网址？**

`127.0.0.1` 指访问者自己的电脑。当前服务运行在你的电脑上；异地直接共享网址需要另行部署。组员开发时可以拿源码包在自己电脑启动。

**现在最建议先做什么？**

先完成上面的五步练习。熟悉之后，再试成员、其他项目和排程。真实模型接通前，先使用本说明中的示例指令。


## 切换聊天成员

在顶部“当前聊天成员”选择自己的姓名，再与课伴聊天。对话标题和每条发言都会显示姓名。“我”“我的任务”会按当前成员理解；任务/日程看板默认筛选到该成员，仍可用“所有成员”查看小组整体。成员空闲时间默认打开当前成员。

切换姓名时，对话、待采用草案和“它”的指代分别保存；切换回来或刷新页面会恢复该成员最近的对话。每个项目分别记住当前成员。任务依然是项目共享的，明确指定其他成员任务时仍可协作处理。旧对话保存在“未指定成员（旧公共对话）”，不会自动归到任何人名下；选好成员后开始新成员对话。

这属于本机成员视角切换，尚未实现账号认证或个人空间的访问权限。多人正式在线使用仍需接入手机号/微信登录与服务端权限。


### 成员名为“我”时的说法

当前聊天成员选“甲”时，聊天里说“给我”“给自己”指甲；直接要求创建单项任务但省略负责人时，也默认给甲。若另一位成员的真实姓名叫“我”，需要指向他时明确说“给姓名为我/成员我”，避免把名字和代词混淆。模型会询问缺少的截止日期或时刻，不应再问“给自己还是给甲”。旧对话曾认错身份时，以当前顶部选择为准继续，无需清空历史。


## 等待回复时查看执行进度

发送后，对话里立即出现执行进度卡和等待时间。模型请求期间显示“正在分析你的需求”；实际查询或保存时显示对应步骤，收到工具真实结果后才标记完成。日程不可行会显示冲突或工时缺口，不会把候选当作已保存日程。

回复生成后，进度卡折叠，可点击展开查看本次实际步骤。刷新后仍可在历史“操作记录”中查看实际工具结果；本次浏览器测量的等待秒数不写入历史。它展示处理阶段和真实工具状态，不展示模型内部推理或虚构百分比。

网络中断时，不要立刻另发一遍创建任务。浏览器断线不代表后端已停止；先查看任务状态，再使用原请求的“重试”按钮恢复结果，避免重复操作。主动停止后端可能中断处理，应另行核对实际数据。
