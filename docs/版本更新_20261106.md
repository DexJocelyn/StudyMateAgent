# 课伴 StudyMate：2026年11月6日版本

本版延续原课伴项目，将小组分工、个人排程和作业提交检查放在同一个项目中。组员已审核当前版本，本次将源码更新到原团队仓库，保留此前提交历史。

## 本版主要变化

- 三个主要入口：帮小组分工、安排我的时间、检查作业。
- 团队分工前读取实际成员名单，修正未明确要求时将全组任务都分给当前聊天成员的问题；采用草案前仍需人工核对。
- 个人排程只安排当前成员的任务，保留其他成员日程；根据已保存的未来空闲时段、预计工时和截止时间检查冲突与缺口。
- 任务支持暂停、继续、完成和明确转交；项目支持重命名、归档与恢复。
- 作业检查支持TXT、Markdown、DOCX正文，对照老师要求展示文字依据、缺项和待核实项；人工复核后可创建补充任务并定位回工作台。
- 计划和自查报告导出使用便于阅读的中文时间；对话支持Markdown排版、展开阅读与可调整宽度。
- 保留千问真实模型、16个MCP工具、可选联网搜索和独立天气接口；加入书页勾选Logo。
- 提供自己的模型配置入口与Windows/macOS启动脚本。需要兼容工具调用和JSON输出的模型接口，不能仅凭普通聊天成功判断全部功能兼容。

## 已知限制与后续工作

- 成员切换是本地视角选择，尚无个人账号和细粒度权限。
- 各自本机运行时数据库独立；共同编辑需连接同一个运行中的服务。
- GitHub提供源码，不会自动部署FastAPI网站；正式公网运行仍需另行配置。
- 不支持PDF、图片OCR、自动评分或硬件联动；部分设备手动停止朗读仍需修复。
- AI模拟走查属于辅助功能与交互验证，不能替代真实学生需求调研；走查记录与课程报告不随本次公开源码更新发布。
- 导出下载引导、日程草案位置提示和人工复核文案是待实施建议，未作为已修复功能发布。
