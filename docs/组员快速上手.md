# 发给组员：课伴快速上手与实操

课伴是把作业要求变成任务、分工和日程的助理。AI可以实际调用工具保存、查询和修改数据，不能只看一句“操作成功”，还要看右侧卡片和操作记录。

## 先看懂四个位置

| 位置 | 用途 |
| --- | --- |
| 当前项目 | 切换不同小组的作业空间 |
| 当前聊天成员 | 选择自己，以这个姓名与AI对话 |
| 任务／日程 | 看要做什么、安排在什么时候 |
| 右侧成员筛选 | 看自己的或所有人的任务，不会改变聊天身份 |

新建项目先填自己，组员逐个添加。卡片明确显示负责人；别人任务点“切换为某某后操作”后再更新状态。“转交给…”才会改变负责人。目前是手动选择姓名，还没有手机号或微信登录。

## 每人5分钟实操

下面用“乙”举例，正式使用选自己的姓名。请在共享服务的同学按《演示案例》建立的“演示·数据库展示”项目里做，避免新建出互不相同的项目。

该演示用甲、乙两个练习身份，大家可轮流体验；想独立实测时按下一节新建自己的项目。正式小组可以在“成员”中补充真实姓名，人数不限于两人。

1. 打开共享服务的同学提供的网址，选择同一项目，再把“当前聊天成员”选为乙。
2. 输入 `查询我的任务`，应看到乙负责的“整理应用案例”。
3. 在这张卡片上点“开始任务”（已开始可跳过），再点“暂停任务”“继续任务”，核对状态变化。
4. 右侧筛选选“所有成员”，检查甲乙的任务都在、各自负责人正确。看别人的任务不会把它变成自己的。
5. 在此练习项目模拟点自己任务的“标记完成”，再点顶部“导出计划”，下载Markdown核对状态。
6. 刷新，确认任务仍然保存。其他组员刚修改的内容需要点“刷新”查看，目前没有自动推送。

## 想单独练习创建任务

新建“实测·你的昵称”项目，“你的姓名或昵称”填写本人，不用添加其他人。在已连接模型的模式里输入：

```text
请给我创建一项“检查课程笔记”的任务，预计20分钟，截止北京时间2026年10月25日22:00。信息已经确认，请实际保存。
```

日期过期时改为未来的明确日期。若页面显示“演示模式”，改用固定规则句：

```text
创建任务：检查课程笔记，我，20分钟，2026-10-25 22:00截止
```

两个句子二选一，不要重复创建。确认负责人是自己，再试开始、暂停、继续、模拟完成和导出。

## 语音怎么用

点“语音输入” → 等“正在聆听” → 说话。临时停下点“暂停”，补充点“继续输入”，说完点“停止输入”，检查文字后点“发送”。累计聆听60秒或浏览器结束时会提示。文字不会自动发送；“停止朗读”控制的是AI朗读。

- 我测试的项目、任务及操作顺序：
- 预期结果／实际结果：
- 发现的问题和复现步骤：
- 截图或录屏（不要包含密钥）：

使用共享服务的同学共享的服务时，任务在同一台服务器保存。拿源码自己启动时，默认是自己电脑的独立数据，不会自动同步到共享服务的同学电脑；源码包默认不带模型密钥。
