# 个人任务与时间安排

## 组员怎么用

1. 选择当前项目，在“你是谁”中选择自己的姓名。
2. 默认查看“我的”任务。想看团队整体情况时，点击右侧“全组”；查看范围不会改变聊天身份。
3. 点击首页“安排我的时间”，填写“我的空闲时间”。保存明确的日期和起止时刻。
4. 点击“生成我的日程草案”。程序通过 MCP 读取你的任务和空闲时间，按最早截止优先排程；其他成员未填写空闲时间，不会阻止你的个人安排。
5. 核对“我的日程草案”，点击“确认并保存”。此次只替换自己的日程，其他成员已有安排保留。
6. 时间变化时重新生成个人草案；也可以点击“清空我的日程”，保留任务和空闲时间，之后再安排。

## 小组协调怎么用

“帮小组分工”把老师要求带入对话，生成分工草案；确认后创建正式任务。

在右侧切到“全组”，可以查看所有人的任务与日程；“生成全组日程草案”和“清空全组日程”会作用于全组范围，界面会明确标注。成员视角仍是手动选择，不是个人账号权限。

## 一个练习

新建两人项目“小组展示练习”，成员小陈、小肖，分别有90分钟和60分钟的任务。截止时间填未来的明确日期，例如2026年11月8日20:00。

- 小肖先保存自己的空闲时段并生成、确认个人日程。
- 切为小陈，填写2026年11月6日19:00—21:00空闲。
- 点击“安排我的时间”→“生成我的日程草案”，核对自己的90分钟安排，再确认保存。
- 切“全组”，应同时看到小陈和小肖各自的安排；小陈重排或清空自己的日程，不会移除小肖的安排。

示例日期需随实际使用日期更新。任务已过期时，先与成员确认新的截止日期；系统不会自动延期。

## 当前规则

- 按已保存的预计用时排程，尚未记录实际已投入工时，进行中任务仍使用其预计总用时。
- 已完成任务不参与排程；暂停任务仍属未完成，不自动顺延截止时间。
- 只有可行时才生成待确认草案；不足时说明缺少的空闲时段、逾期任务或未排下的用时。
- 再次生成日程会替换本会话旧的日程草案；如果本次不可行，旧的日程草案也不再可采用。
- 生成草案、确认保存和清空按钮执行真实 MCP 工具，不额外请求大模型；自然语言安排仍可以通过千问选择相应工具。
- 多人先后修改使日程版本变化时，旧草案会被拒绝保存，需要重新生成，避免覆盖他人的最新安排。
- 页面空闲时自动检查共享任务和日程变化；正在编辑的文字和表单保留。
