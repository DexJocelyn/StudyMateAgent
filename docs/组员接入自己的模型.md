# 组员接入自己的模型

课伴目前使用 OpenAI 兼容的 Chat Completions HTTP 接口，模型地址、模型标识和密钥均由后端配置。千问已经过真实调用验证；其他模型是否完全兼容，需要按下面的步骤实测。

## 先确认使用方式

- **自己电脑运行完整源码**：可以在自己的 `.env` 配置自己的模型，不影响其他电脑。
- **打开同一个共享网站**：当前使用共享主机上的模型配置。网页切换成员不会切换模型，修改共享主机配置会影响这台主机上的所有成员。
- **Windows 教室客户端安装包**：这是连接共享主机的入口，没有独立的 Python 后端；要在自己电脑接模型，应使用完整源码，按 README 创建本机运行环境。

## 模型接口需要满足什么

1. 提供 OpenAI 兼容的 `/chat/completions` 接口和 Bearer API Key 鉴权。
2. 支持 `messages` 多轮对话、`tools` 工具声明、`tool_calls` 和 `tool` 消息回传；普通聊天成功不代表可以执行 Agent 工具。
3. “检查作业”还会请求 `response_format={"type":"json_object"}`，并使用 `temperature=0.1`、`max_tokens=10000`；对话使用 `temperature=0.2`。模型或服务商需兼容这些参数，否则需要针对接口做适配。

模型名称使用服务商文档或控制台里的真实 API 模型 ID。聊天网页账号或会员订阅本身不等于可用的 API。

## 本机配置

在完整源码根目录找到 `.env.example`。首次运行复制为 `.env`；已有 `.env` 时，保留原有其他配置，只修改模型相关项。Windows 注意文件不要被保存成 `.env.txt`。

```dotenv
AGENT_MODE=llm
MODEL_BASE_URL=替换为服务商的OpenAI兼容BaseURL
MODEL_NAME=替换为真实模型ID
MODEL_API_KEY=只在自己电脑填写自己的密钥
MODEL_TIMEOUT=60
AGENT_MAX_ROUNDS=8
```

`MODEL_BASE_URL` 填服务商的接口根地址。程序会自动追加 `/chat/completions`，不要在这里重复填写这个后缀。不同平台的 Base URL 不一定都以 `/v1` 结尾，按服务商实际文档填写。

改完后停止本机课伴并重新启动：Windows 双击“启动课伴-Windows.bat”；Mac 双击“启动课伴.command”。配置和依赖检查通过，只代表本机配置可读取，并不代表模型调用已成功。

密钥不提交到仓库、不放进截图，也不需要发到团队聊天。接入问题只需提供平台名、模型 ID、脱敏后的错误信息。

## 建议的实际验收

新建“模型实测·自己的姓名”项目，选择自己的成员身份，依次测试：

1. **普通对话**：问“用两句话解释数据库索引”，确认有正常回复。
2. **工具执行**：明确指定一项任务的标题、预计分钟数和未来截止日期，让课伴创建；核对右侧卡片、负责人、时间和真实工具记录，再刷新页面确认任务保留。
3. **多轮修改**：继续说“把刚才那项任务暂停”，检查卡片变成“已暂停”。
4. **天气工具**：问“广州明天天气怎么样”，检查是否执行天气查询、是否给出有效日期和来源。
5. **作业检查**：保存一条老师要求和一份文字材料，点击开始检查；确认返回有原文引用、可保存的检查结果，而非普通聊天文字。

天气和联网搜索是课伴自己的工具，不是换了模型就自动增加的能力。天气接口默认无需额外密钥；搜索需要另配 `TAVILY_API_KEY`。模型未调用工具、接口报错或检查结果不符合 JSON 要求，都应如实记录，不能只凭“聊天有回复”判定整个 Agent 接入成功。

记录：平台、模型 ID、操作系统、上述各项是否通过、失败时的 HTTP 状态和脱敏错误。遇到 401/403 核对密钥与权限，404 核对地址和模型 ID，400 核对参数、工具调用与 JSON 模式兼容性；具体含义以服务商错误信息为准。
