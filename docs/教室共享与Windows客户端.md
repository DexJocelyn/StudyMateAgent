# 课伴教室共享与 Windows 客户端

适合大家在同一教室、同一 Wi-Fi 或热点下共同使用。Mac 负责运行后端与保存数据，Windows 只安装连接入口，无需安装 Python 或填写千问密钥。

## 主机同学

1. Mac 连接大家共同使用的 Wi-Fi，双击项目根目录的 **启动教室共享.command**。
2. 终端显示类似 `http://10.0.0.5:8766` 的地址。共享服务后台运行，启动窗口可关闭。
3. 将这个地址提供给组员。教室入口默认免登录，不需要注册账号或输入密码；模型配置保留在 Mac。
4. 可以继续从 `http://127.0.0.1:8000/` 使用，Windows 组员从共享地址访问，两者读写同一个数据库。
5. 共享期间程序会防止 Mac 自动闲置休眠，停止共享后结束这项保持唤醒；仍需保持电脑开机联网，不要合盖或手动睡眠。换 Wi-Fi 或主机地址变化后，重新启动教室共享，告诉组员更新地址。
6. 结束时双击 **停止教室共享.command**。它只停止教室分享及自己启动的后端，不会停止原本就在运行的本机服务。

查看状态：

```bash
.venv/bin/python scripts/lan_host.py status
```

日志位于 `data/lan/`。此目录和访问配置都不应提交到公共仓库。

## Windows 组员

1. 接收 `课伴教室版-Windows客户端安装包.zip`，完整解压。
2. 双击 **安装课伴.cmd**，生成桌面“课伴教室版”和“课伴-修改主机地址”。安装在当前用户目录，无需管理员权限。
3. 双击“课伴教室版”，输入 Mac 提供的地址，无需账号密码。
4. 选择同一个项目，再选自己的姓名。成员视角仍是手动选择，不是个人账号登录。
5. 其他人修改任务、成员和日程后，页面空闲时约每3秒自动检查并更新任务看板，也可手动刷新。聊天和正在编辑的表单不会被其他人的对话覆盖。

有 Microsoft Edge 时，入口以独立应用窗口打开；否则用默认浏览器。客户端不是离线后端，不会在每个组员电脑建立独立数据库。

更换地址：双击桌面“课伴-修改主机地址”。卸载：开始菜单 → 课伴教室版 → 卸载课伴。卸载入口不会删除 Mac 上的项目。

## 教室第一次实测

- 主机开启共享后，先让一台 Windows 电脑在浏览器输入共享地址。能打开项目再安装入口，方便区分网络问题与安装问题。
- 一位同学新建一个测试任务，另一位同学保持同一项目页面空闲，检查约3秒内是否出现；再按自己的成员身份更新任务状态，验证双方看到相同结果。
- 上传一份测试材料，保存老师要求，检查作业页面的保存和删除操作；验证新入口支持这些操作。
- 千问、搜索、天气由 Mac 联网请求。客户端不需要安装模型或设置密钥。

## 连接限制

同一个校园 Wi-Fi 可能启用设备隔离，导致同学之间不能互访。此时换用共同的、允许设备互访的热点或路由器；安装包无法改变校园网络规则。

主机系统如询问是否允许入站连接，只为实际使用的课伴服务允许必要连接，不要关闭整个防火墙。入口仅绑定检测到的具体内网 IPv4 地址，不启动公网隧道。默认免登录，能连接该地址的同网设备也能访问项目、使用 AI，适合教室或共同热点下使用。网页仍需选择成员姓名来区分对话和任务。

如以后希望教室入口恢复小组密码，可运行 `.venv/bin/python scripts/lan_host.py start --require-password`。此选项与公网分享独立，公网分享仍要求密码。

局域网 HTTP 下，麦克风输入可能受浏览器安全上下文限制；文字对话、任务、日程和材料操作不依赖麦克风。Windows 10/11 客户端使用系统 PowerShell 和浏览器，受单位统一管控的电脑可能限制脚本执行；不要绕过系统防护，改用浏览器访问同一共享地址即可。

Windows 安装器是在 Mac 上生成的透明 CMD/PowerShell 客户端入口包，不是已签名的原生 EXE 安装器。Windows 实机安装、桌面图标、Edge 应用窗口及教室跨设备互访，需要在 ROG/组员电脑完成最终验收。

## 重新打包

```bash
.venv/bin/python scripts/package_lan_client.py
```

生成的包只包含客户端入口、地址配置和说明，不包含后端源码、数据库、API Key、小组密码或 Mac 虚拟环境。主机程序更新后客户端打开的就是主机当前版本，一般无需重新安装。
